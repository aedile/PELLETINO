# What SHORYUKEN changed in Musashi

Musashi 4.10, https://github.com/kstenerud/Musashi, commit 313ebf1. MIT
license; see `readme.txt`. Every change in the source is marked `SHORYUKEN:`.

| File | Change | Why |
|---|---|---|
| `gen/m68k_in.c`, `gen/m68kmake.c` | none | Musashi's instruction definitions and its generator, kept so that `m68kops.c` can be made again |
| `m68kops.c`, `m68kops.h` | generated by `tools/gen_m68k.py`, not by hand | Musashi builds a 256 KB table of handler pointers and 320 KB of cycle counts in RAM at start-up. The board has 512 KB of RAM. The generator runs Musashi's own generator, takes out the table builder, and writes what it would have built for a 68000, packed into 30 KB: a table by opcode >> 3 that gives a handler number or a row of eight, the rows, and the handlers and their costs by handler number |
| `m68kops.c` | the FPU and MMU handlers' calls into `m68kfpu.c` and `m68kmmu.h` are removed, and one `fprintf` | a 68000 has neither, and nothing prints on the device |
| `m68kcpu.c` | no `#include "m68kfpu.c"`, `"m68kmmu.h"` | as above; `softfloat/` is not shipped |
| `m68kcpu.c` | `m68k_init()` does not build the opcode table | it is a constant |
| `m68kcpu.c` | `m68k_execute()` finds the handler through `m68ki_handler_of()`, and charges `m68ki_handler_cycles[]` | the constant tables |
| `m68kcpu.c` | `m68k_execute()` no longer copies the sixteen registers before every instruction | they were saved for the bus error exception, which nothing on this machine raises |
| `m68kcpu.c` | `m68k_set_cpu_type()` no longer sets `cyc_instruction` | there is one table of costs, the 68000's |
| `m68kcpu.h` | no `softfloat` headers; `int8`, `int16`, `int32` defined in their place; no `fpr[8]` in the CPU state | no FPU |
| `m68kcpu.h` | includes `cps1_mem.h`, which defines `m68k_read_memory_8()` and the rest as inline functions | a call for every memory access is most of what an interpreter costs |
| `m68kcpu.h` | `CYC_INSTRUCTION[REG_IR]` is `CYC_INSTRUCTION_IR` | costs are by handler |
| `m68kconf.h` | written for this project | it is the file Musashi means its user to write: 68000 only, separate immediate reads, interrupt acknowledge through `cps1_int_ack()` |
| `m68kfpu.c`, `m68kmmu.h`, `m68kdasm.c`, `softfloat/`, `example/`, `test/` | not included | not used |

Only the 68000 is supported by the tables. Asking `m68k_set_cpu_type()` for
anything else will run 68000 instructions at 68000 costs.
