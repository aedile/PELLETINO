# SHORYUKEN

Street Fighter II: The World Warrior, the real ROM, emulated on the Waveshare
ESP32-C6-LCD-1.69. Not a game to play: a bench for finding out what a CPS-1
costs on one 160 MHz RISC-V core with 512 KB of RAM, with every expensive part
behind a switch.

This README is being filled in as the work is measured. What is here has been
measured; the results table and the build-by-build instructions follow the
sweep.

See `LICENSE` and `THIRD_PARTY_NOTICES.md`. No ROMs are included.
